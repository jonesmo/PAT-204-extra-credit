# PAT 204 / 504 / COMPFOR 214 Extra Credit Assignment

This extra credit assignment is worth **1 point**, or:

- 1/3 of a coding HW
- 1 discussion assignment
- 1% of your course grade

## To complete this assignment

1. Fork this repository
2. Navigate into the `submit_here` folder
3. Click `Add file` --> `Create new file`
4. Give your file a name, eg `student-name.md`. It should be a markdown (`.md`) file.
5. In the body of the file, put a link about an artist or artwork we haven't discussed in class. This artwork or artist should use coding in some way. Here's how to create a link in markdown:

```
[Casey Reas](https://reas.com/)
```

6. Click the green `Commit changes...` button
7. In the popup, leave everything as-is and click `Commit changes`
8. Click `Contribute` -> `Open pull request`
9. Give your pull request a name, eg `Student Name, Artist/Artwork Name`
10. Click the green `Create pull request` button at the bottom

At this point, you have created a pull request against my `jonesmo/PAT-204-extra-credit` repository and the assignment is complete.
